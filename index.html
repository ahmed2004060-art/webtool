🤖 بناء تطبيق APK عبر GitHub

يرفع المشروع إلى GitHub ويبنيه هناك مجانًا، ثم يعطيك رابط تحميل APK.

كيف أحصل على Token من GitHub؟
  1. افتح github.com وسجّل دخول (أنشئ حساب إن لم يكن لديك).
  2. اذهب إلى: Settings ← Developer settings ← Personal access tokens ← Tokens (classic).
  3. اضغط Generate new token (classic).
  4. اختر صلاحية repo وworkflow فقط.
  5. اضغط Generate ثم انسخ الـ Token (يبدأ بـ ghp_).
